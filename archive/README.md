# Archive

Stale, duplicate, or superseded artifacts moved here during the 2026 repo
cleanup. Nothing in this tree is imported by the engine, CI, or default pytest
runs. Local model payloads and generated caches are ignored instead of being
copied into this archive.

## Restore

Move files back to their original paths if needed. For the stale forward module, restore to
`rwkv_ssd/runtime/rwkv7_forward.py` only if you intentionally want the older copy — use
`rwkv_ssd/backends/rwkv7_forward.py` for all new work.
