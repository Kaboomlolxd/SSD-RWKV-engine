# Paper Set

Optional LaTeX drafts (academic). **Not the inference engine** — see [`../ENGINE.md`](../ENGINE.md).

This folder contains standalone LaTeX paper drafts derived from feasibility / thesis ideas.

## Included Papers

1. `paper1_o1_streaming_foundation.tex`
   From KV random IOPS to sequential layer streaming for O(1) recurrent-state inference.

2. `paper2_compression_thermal.tex`
   Conservative Compression Trinity accounting plus thermal duty-cycle interpretation.

3. `paper3_scheduler_prefetch.tex`
   Unified scheduler view of micro-pipelining, recurrent MTP, and gate-driven prefetch.

4. `paper4_resilient_model_arrays.tex`
   Append-only adapter logging and application-layer erasure coding for SSD model arrays.

5. `paper5_sector_nine_engram.tex`
   Sector-Nine constrained-probe layout for SSD-backed episodic memory lookups.

## Why These Are Grouped This Way

The goal of this set is not one tiny paper per mechanism. It is one paper per publishable research story. Closely related ideas were grouped when a single idea would otherwise be too thin or too speculative to stand on its own.

## Ideas Deliberately Not Promoted To Standalone Papers Yet

- Ouroboros weight-sharing architecture
- deeper computational-storage / in-storage selective-scan proposals
- highly speculative NAND-physics control ideas
- additional synthesis-heavy scheduler variants that still need stronger comparative evaluation

These ideas may still be worth future papers, but they need stronger evidence or a more focused experimental story before they are promoted to standalone drafts.
